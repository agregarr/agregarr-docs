# Config Options

1. **Choose a source** – select the parent source you want to use. Ensure your API keys are set if required.
2. **Pick a sub-type** – select the specific list you want to use, inlcuding custom lists
3. **Select target libraries** – select one or many libraries, individual collections will be created for each

- [Library Selection](/docs/options/library-selection) – choose which Plex libraries receive the collection.
- [Titles & Templates](/docs/options/titles) – control how Agregarr names the collection per library.
- [Source Specific Options](/docs/options/source-specific-options) – settings that depend on the chosen provider or tag type.
- [Visibility](/docs/options/visibility) – decide where Plex surfaces the collection and how inactive periods behave.
- [Max Items](/docs/options/max-items) – cap how many items Plex keeps in the collection.
- [Unwatched Collections](/docs/options/unwatched-collections) – create smart, per-user unwatched views.
- [Posters](/docs/options/posters) – auto-generate artwork or upload custom posters per library.
- [Time Restrictions](/docs/options/time-restrictions) – schedule when a collection is considered active.
- [Custom Sync Timing](/docs/options/custom-sync-timing) – override the default sync cadence or supply a cron expression.
- [Missing Items & Auto Requests](/docs/options/missing-items) – optionally download or request items that are missing from Plex.
- [Random Home Order](/docs/options/random-home-order) – shuffle the collection's position on the Plex home screen.

## Preview Before Saving

When all mandatory fields are satisfied the **Preview Collection** button activates. Use it to view matching items in Plex and add missing items individually.
