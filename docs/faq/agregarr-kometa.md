# Agregarr & Kometa Comparison

## Core Differences

**GUI vs YAML**

Agregarr's main and obvious difference is that it is sctrictly a GUI where as aside from Kometa's QuickStart it is run purely in YML and CLI commands.

**The Experience**

One of the first things you would notice is the ease of getting things up and running in Agregarr vs Kometa. Depending on the OS things can get a bit tricky with Kometa, running a virtual environment in windows for example. Agregarr is as easy as installing Docker Desktop and running a Docker-Compose.

Kometa is a very powerful and polished tool for those willing to learn it or already know how. It offers many ways to fully customize your Plex experience, diving deep under the hood and using every bit of data can leverage.
Agregarr is quite powerful too, but lacks many of the additonal and more advanced features of Kometa. It is aimed for those who struggle with Kometa, YML and CLI or maybe just don't want to be bothered learning everything required of it. 
With Agregarr the hard work is done for you in the background while you simply fill in the blanks and use features like drag 'n' drop to organize. Agregarr is more than just a QuickStart as far as collections, posters and overlays are concerned. It is quite adeguate for most users needs to have a unique and professional Plex experience while still powerful enough that even the customizers out there should be quite satisfied with their results as well.

Please keep in mind, Kometa is a very seasoned application while Agregarr is still in early development and will likely never offer everything Kometa does, nor does it strive to. It's focus is mainly on ease of use for collections, posters and overlays.
