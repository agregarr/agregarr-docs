# Contributing Translations

Agregarr is available in multiple languages, and we welcome contributions to help translate the application into more languages or improve existing translations.

## Translation Status

<WeblateLanguageBadges project="agregarr" component="agregarr-frontend" />

## How to Contribute Translations

We use [Weblate](https://weblate.org/) to manage translations.

1. **Visit the Weblate project**: [https://hosted.weblate.org/projects/agregarr/](https://hosted.weblate.org/projects/agregarr/)
2. **Sign in or create an account** on Weblate (you can use GitHub, Google, or other OAuth providers)
3. **Select a language** to translate or improve
4. **Start translating**

### Suggesting a New Language

If your language isn't currently supported, you can either request a new language directly on Weblate, or create an issue on [GitHub](https://github.com/agregarr/agregarr/issues)

## Thank You

A huge thank you to all our translation contributors who help make Agregarr accessible to users around the world!
