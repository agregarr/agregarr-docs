# Navigating the UI

The sidebar shows every page. Use this list as a quick reference.

- **Home** – Arrange the collections that appear on Plex home screens. [Home guide](/docs/ui/home)
- **Recommended** – Recommended tab for each library (shared ordering with Home). [Recommended guide](/docs/ui/recommended)
- **Library** – Arrange the collections that appear inside each Plex library (independent ordering). [Library guide](/docs/ui/library)
- **All Collections** – View and edit every collection, hub, and pre-existing list. [All Collections guide](/docs/ui/all-collections)
- **Posters** – Create templates and manage saved posters. [Posters guide](/docs/ui/posters)
- **Dashboard** – Check most viewed collections, and missing items (work in progress). [Dashboard guide](/docs/ui/dashboard)
- **Settings** – Configure plex server, sources, downloads, jobs, logs, and about info. [Settings guide](/docs/ui/settings)
